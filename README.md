# Bguidolim Tap

## How do I install these formulae?

`brew install bguidolim/tap/<formula>`

Or `brew tap bguidolim/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "bguidolim/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
